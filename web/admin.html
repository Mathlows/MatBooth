Wi-Fi de la borne

La borne crée son propre réseau Wi-Fi : les invités le rejoignent avec le premier QR code, puis ouvrent leur photo avec le second. Fonctionne partout, sans le Wi-Fi de la salle. Il reste actif après un redémarrage, jusqu'à ce que vous le désactiviez.

Pendant qu'il est actif, la borne n'a plus internet par Wi-Fi : les e-mails attendent et partiront une fois le Wi-Fi de la borne désactivé (ou tout de suite avec un câble Ethernet). Si vous administrez depuis un téléphone, rejoignez ensuite ce réseau et ouvrez http://10.42.0.1:8000/admin.

Ou Wi-Fi existant (QR code)

Si le Wi-Fi de la borne est désactivé, le téléphone du client doit être sur le même réseau que la borne. Si vous indiquez ce Wi-Fi, un second QR code permet de s'y connecter en un geste. Certaines box isolent les appareils Wi-Fi entre eux : le QR code ne marche alors pas.

E-mail (serveur d'envoi)

Les e-mails attendent dans la borne et partent dès qu'internet est disponible. Avec Gmail : serveur smtp.gmail.com, port 587, et un « mot de passe d'application » (pas le mot de passe du compte).
